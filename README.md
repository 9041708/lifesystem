# Life · 可自主部署的企业管理系统（免费授权）

> 一套可以装在自己服务器上的管理系统：工单、OA、知识库、社区、薪酬、插件。  
> 部署包免费下载，授权永久免费，数据完全放在你自己的服务器上。

**官网**：<https://lifebs.cn>  
**部署文档**：<https://lifebs.cn/docs.php>  
**插件库**：<https://lifebs.cn/portal/plugin_market.php>

## 这是什么

Life 是一套 PHP + MySQL 的 Web 管理系统，覆盖中小企业日常要用的几块：

| 模块  | 能做什么                   |
| --- | ---------------------- |
| 工单  | 提交、指派、流转、SLA、模板、统计     |
| OA  | 审批流、待办、云笔记、合同、日程、汇报、问卷 |
| 知识库 | 文章分类、在线考试、AI 辅助写作      |
| 社区  | 团队公告、部门交流、内容管理         |
| 薪酬  | 考勤、工资表、社保、借款、导出        |
| 导航  | 团队网址导航、提交审核            |
| 插件  | 官方与第三方插件，安装即用          |

所有模块共用一套账号与权限体系，装一次就能一起用。

## 和 SaaS 的区别

|      | Life（自部署） | 常见 SaaS |
| ---- | --------- | ------- |
| 数据位置 | 你自己的服务器   | 厂商云端    |
| 费用   | 授权免费、永久   | 按人/按年订阅 |
| 功能限制 | 无阉割版      | 免费版常有限制 |
| 维护   | 自己负责服务器   | 厂商负责    |
| 定制   | 可以改代码     | 一般不行    |

**适合谁**：有自己的服务器（或有能力买一台）、在意数据归属、不想按年付费的团队。  
**不适合谁**：完全不想碰服务器、希望开箱即用不管运维的团队 —— 这种情况用 SaaS 更省心。

## 环境要求

- PHP 7.4 ~ 8.2（推荐 8.0 / 8.1）
- MySQL 5.7 / 8.0（MariaDB 10.3+ 亦可）
- Nginx 或 Apache
- 扩展：pdo_mysql、mbstring、gd、fileinfo、curl
- 内存 2G 起步，成员较多建议 4G

宝塔面板可以一键装好上述环境。

## 快速开始

```bash
# 1. 在宝塔新建站点（PHP 8.0 + MySQL），记下数据库信息
# 2. 上传部署包到站点根目录并解压
# 3. 访问安装向导
https://你的域名/install/install.php

# 4. 按向导完成：安装密钥 → 环境检测 → 数据库 → 管理员与邮件 → 授权
# 5. 到官网用邮箱获取授权码，填进后台「授权管理」
```

### 定时任务（建议配置）

导出、备份、提醒、日志清理依赖服务器计划任务，宝塔「计划任务 → Shell 脚本 / 每 5 分钟」：

```bash
/www/server/php/80/bin/php /www/wwwroot/你的站点/cron/process_system_tasks.php >> /www/wwwroot/你的站点/cache/cron_task.log 2>&1
```

不配置也能跑，但任务会在有人访问页面时执行，表现为「页面卡一下」。

### 目录权限

```bash
chown -R www:www .
find . -type d -exec chmod 755 {} \;
find . -type f -exec chmod 644 {} \;
```

不需要 777。详见 [目录权限文档](https://lifebs.cn/docs/permissions.php)。

## 授权说明

- **免费**：部署包、授权码、插件都不收费，无按年订阅
- **永久**：目前签发的均为长期授权，不会到期
- **绑定域名**：一个域名一个授权，用邮箱自助获取
- **换域名**：需要重新取码，数据不受影响
- **更新**：后台「更新管理」一键升级，config / uploads / runtime / plugins 受保护，不覆盖你的修改

授权仅用于防止部署包被随意分发，以及作为更新通道的凭据。

## 常见问题

**Q：代码开源吗？**  
A：不开源发。可以免费使用、可以自己改代码适配，但分发与二次销售需要授权。

**Q：真的永久免费吗？以后会不会收费？**  
A：目前授权与插件都不收费，也没有付费功能版。如果未来有商业版本，现有授权继续有效。

**Q：能商用吗？**  
A：可以用于自己的经营场景，具体范围以随包附带的授权协议为准。

**Q：服务器不能上外网能部署吗？**  
A：激活时联网一次即可，日常使用不依赖外网。

**Q：有没有演示站？**  
A：官网产品页可查看截图与演示地址，部分产品提供在线演示账号。
